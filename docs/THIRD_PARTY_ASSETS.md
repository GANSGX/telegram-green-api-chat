# Сторонние материалы

## Фон Telegram Web A

`public/telegram-pattern.svg` и `public/telegram-logo.svg` — неизменённые оригинальные SVG из официального клиента Telegram Web A. Знак также используется как favicon.

[Исходный фон](https://github.com/Ajaxy/telegram-tt/blob/ea0d226147a80f05253bf1a6ffef08d694b8e6e4/src/assets/pattern.svg)

[Исходный знак](https://github.com/Ajaxy/telegram-tt/blob/ea0d226147a80f05253bf1a6ffef08d694b8e6e4/src/assets/telegram-logo.svg)

[Исходное оформление фона](https://github.com/Ajaxy/telegram-tt/blob/ea0d226147a80f05253bf1a6ffef08d694b8e6e4/src/styles/_patternBackground.module.scss)

Лицензия репозитория Telegram Web A — GNU GPL v3. Копия включена в `public/licenses/TELEGRAM-WEB-A-LICENSE`. Авторство и условия распространяются на оригинальный SVG.

Стили используют оригинальную повторяющуюся маску шириной 430 px на чёрной основе. Вместо анимированного градиента оригинала применён статический CSS-градиент в тех же цветах.

## Roboto

Четыре файла WOFF2 в `public/fonts` содержат оригинальные латинский и кириллический наборы Roboto 2 в начертаниях 400 и 500. Файлы локально переименованы для читаемости. Содержимое шрифтов не изменено.

[Шрифты в официальном клиенте](https://github.com/Ajaxy/telegram-tt/tree/ea0d226147a80f05253bf1a6ffef08d694b8e6e4/src/assets/fonts)

Roboto распространяется Google по Apache License 2.0. Копия включена в `public/licenses/ROBOTO-LICENSE`.

## Данные демонстрации

Имена, переписка и ответы в демоверсии вымышлены. Личная переписка, фотографии контактов и сведения об аккаунте из присланных скриншотов в проект не включены.
