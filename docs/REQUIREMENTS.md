# Требования и критерии приёмки

Telegram-клиент на React для отправки и получения сообщений через GREEN-API. Основной сценарий включает подключение инстанса, создание чата по номеру телефона и обмен текстовыми сообщениями.

## Основные требования

| Требование                               | Реализация                                                                  |
| ---------------------------------------- | --------------------------------------------------------------------------- |
| Интерфейс отправки и получения сообщений | Список чатов, переписка, поле ввода и статусы сообщений                     |
| Интеграция с GREEN-API                   | Серверный клиент API для Telegram-инстанса                                  |
| Текстовые сообщения                      | Отправка текста до 4096 символов и обработка входящих текстовых уведомлений |
| Интерфейс мессенджера                    | Тёмное оформление в стиле Telegram Web, адаптивная компоновка               |
| Простой основной сценарий                | Подключение, создание чата, отправка сообщения и получение ответа           |
| Отправка через SendMessage               | Вызов `sendMessage` с полями `chatId` и `message`                           |
| Получение через HTTP API                 | Последовательные вызовы `receiveNotification` и `deleteNotification`        |
| React                                    | React 19 и TypeScript                                                       |

## Сценарий приёмки

1. Ввести `apiUrl`, `idInstance` и `apiTokenInstance` авторизованного Telegram-инстанса.
2. Создать чат по номеру телефона в международном формате.
3. Написать сообщение и отправить его получателю.
4. Убедиться, что сообщение появилось в Telegram.
5. Ответить из Telegram и убедиться, что ответ появился в том же чате без дубля.

`apiUrl` берётся из кабинета GREEN-API. Если поиск по телефону недоступен из-за настроек приватности Telegram, получателя можно выбрать по `@username`.

## Дополнительные возможности

- Несколько чатов, поиск, счётчики непрочитанных сообщений и отдельные черновики
- Файлы, фото, видео и аудиофайлы до 16 МиБ с подписью до 1024 символов
- Предпросмотр вложений, скачивание и встроенное воспроизведение поддерживаемых браузером форматов
- Демоверсия с локальными сообщениями без подключения аккаунта
- Поиск по тексту переписки и вставка эмодзи

## Обработка ошибок

- Невалидные реквизиты и неподходящий тип инстанса отклоняются при подключении.
- Пустые сообщения, превышение лимита текста и недопустимые размеры файлов блокируются до отправки.
- Повтор одного запроса с тем же `clientId` не создаёт повторную отправку в пределах серверной сессии.
- Неопределённый результат отправки отображается отдельно и не вызывает автоматический повтор.
- Повторно полученные уведомления не дублируют сообщения в чате.
- После временного обрыва соединения получение событий возобновляется.
- Выход завершает сессию и очищает локальную историю подключения.
